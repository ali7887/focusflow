# 🧠 FocusFlow - Smart To-Do App with Mood Tracker

A React + Tailwind app with mood tracking per task. Built for showcasing CRUD, state management, UI filtering, and localStorage.

## 🔧 Features
- Add, edit, delete tasks (CRUD)
- Mood selector (😄 😐 😞)
- Filter tasks by mood
- LocalStorage persistence
- Responsive Tailwind UI
- Built with Vite + React
